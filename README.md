# 📈 국내 주식 실시간 검색 순위 텔레그램 봇  

국내 주식의 실시간 검색 순위(TOP 20)를 수집해 텔레그램(Telegram)으로 전송하는 자동화 봇입니다.  
주력 데이터 소스에 문제가 생기더라도 미리 정해둔 우선순위에 따라 다음 소스로 자동 전환(Fallback)되며, 모든 소스가 실패할 경우 실패 원인을 텔레그램으로 알려줍니다.

---

## 🔄 데이터 수집 우선순위  ( 다음 금융 '실시간 검색 순위 ) 네이버 실패

1. **네이버 금융 '검색상위 종목'** (`https://finance.naver.com/sise/lastsearch2.naver`) — 실시간 검색 순위 TOP 20 수집
2. **다음 금융 '실시간 검색 순위'** (`https://finance.daum.net/api/search/ranks?limit=20`) — JSON API 기반 검색 순위 수집
3. **네이버 모바일 증권 시가총액 상위** (`https://m.stock.naver.com/api/stocks/marketValue/KOSPI`) — 대체 데이터(시가총액 기준)
4. **FinanceDataReader 시가총액 상위** — 최후의 대체 데이터(KOSPI/KOSDAQ 시가총액 기준)

* 앞선 소스가 오류를 내거나 수집 개수가 부족(5개 미만)하면 다음 소스로 자동 이동합니다.
* 모든 소스 수집에 실패하면 실패 사유를 정리해 텔레그램 알림을 보내고 종료 코드 `1`로 마무리합니다.
* 검색 순위 소스가 모두 실패해 시가총액 대체 데이터로 발송된 경우 메시지 하단에 대체 데이터 안내 문구가 함께 표시됩니다.

---

## ✨ 주요 기능

* **다중 소스 자동 폴백 & 오류 리포트**: 수집 실패 시 원인을 로깅하고 텔레그램으로 실패 내역을 전달합니다.
* **운영 시간 방어 로직**: 한국 시간(KST) 기준 **04:00 ~ 23:00** 사이에만 동작합니다. (`FORCE_RUN=1` 환경변수를 설정하면 시간 제한 없이 실행 가능)
* **JSON 데이터 저장**: 수집 결과(`updated_at`, `source`, `errors`, `items`)를 `data/ranking.json` 파일로 저장합니다.
* **하이퍼링크 및 등락 아이콘 지원**: 각 종목명에 네이버 금융 종목 상세 페이지 링크가 연결되며, 등락률에 따라 `🔺`, `🔻`, `➖` 아이콘이 표시됩니다.
