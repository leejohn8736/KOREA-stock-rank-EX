# 📈 국내 주식 실시간 검색 순위 텔레그램 봇  

국내 주식의 실시간 검색 순위(TOP 20)를 수집해 텔레그램(Telegram)으로 전송하는 자동화 봇입니다.  
주력 데이터 소스에 문제가 생기더라도 미리 정해둔 우선순위에 따라 다음 소스로 자동 전환(Fallback)되며, 모든 소스가 실패할 경우 실패 원인을 텔레그램으로 알려줍니다.
